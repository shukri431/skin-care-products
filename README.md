# 🌟 Skin-Care Products Web

A premium and modern skincare e-commerce website built with **HTML, CSS, and JavaScript**.

The project provides a smooth and elegant shopping experience where users can explore skincare products, view detailed product information, add products to a shopping cart, manage quantities, and complete a checkout form.

---

## ✨ Features

### 🎨 Modern & Luxury Design
- Clean and elegant skincare-inspired UI
- Premium product presentation
- Smooth animations and transitions
- Professional typography and layout
- Fully responsive design

### 🛍️ Product Experience
- Dynamic product rendering using JavaScript
- Product categories
- Product cards with images, names, prices, and descriptions
- Detailed product information
- Product quantity selection
- Add products directly to the cart

### 🛒 Shopping Cart
- Add products to cart
- Increase or decrease product quantity
- Remove products from cart
- Automatically calculate totals
- Cart item counter
- Persistent cart data using Local Storage

### 💳 Checkout
- Simple and user-friendly checkout form
- Customer information fields
- Order summary
- Total price calculation
- Form validation

### 📱 Responsive Design
The website is designed to provide a consistent experience across:

- 💻 Desktop
- 💻 Laptop
- 📱 Tablet
- 📱 Mobile

---

## 📄 Pages

The project includes several interactive pages:

- 🏠 **Home Page** — Introduces the skincare brand and featured products
- 🧴 **Products Page** — Displays the available skincare products
- 🔎 **Product Details Page** — Shows detailed information about a selected product
- 🛒 **Cart Page** — Allows users to manage their selected products
- 💳 **Checkout Page** — Allows customers to enter their information and review their order

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| **HTML5** | Website structure and content |
| **CSS3** | Styling, layout, animations, and responsive design |
| **JavaScript** | Dynamic functionality and user interactions |
| **Local Storage** | Saving cart information in the browser |
